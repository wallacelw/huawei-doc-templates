== Acessar o Console da Huawei Cloud

[.objectives]
====
[.general-objective]#Este laboratório apresenta o acesso ao Console da Huawei Cloud,
desde o login no portal até a navegação básica pelo painel de serviços.
Ao concluir, você será capaz de autenticar-se na plataforma, selecionar a
região desejada e localizar os principais serviços do catálogo.#

*Pré-requisitos:*

- Conta IAM ativa na Huawei Cloud (com usuário e senha válidos).
- Navegador web atualizado (Google Chrome, Mozilla Firefox ou Microsoft Edge).
- Acesso à internet e permissão para acessar o endpoint
  `console.huaweicloud.com`.
====

NOTE: Este guia cobre o fluxo básico de acesso ao Console. Para operações
avançadas, consulte a documentação oficial da Huawei Cloud.

=== Acessar e navegar no Console

*Objetivo:* Realizar o login no portal da Huawei Cloud e percorrer os
elementos principais do Console: catálogo de serviços, seletor de região
e área de notificações.

*Passo a passo:*

. Acesse a https://www.huaweicloud.com/intl/en-us/[Huawei Cloud]
  e, no canto superior direito, clique em *Console*.
+
.Tela de login do Console
image::assets/exemplo-login.png[width=50%]
+
. Informe o nome de usuário e a senha da sua conta IAM e clique em
  *Log In*. Se a conta tiver autenticação em dois fatores habilitada,
  informe o código enviado ao seu dispositivo.
+
. Após o login, o painel principal do Console é exibido. No canto
  superior esquerdo, abra o catálogo de serviços clicando no ícone de
  menu e navegue até menu:Console[Elastic Cloud Server].
+
image::assets/exemplo-menu.png[width=80%]
+
. No canto superior direito, selecione a região em que seus recursos
  serão criados (por exemplo, `sa-brazil-1`).
+
NOTE: A região selecionada no Console define onde os novos recursos são
provisionados. Recursos já existentes em outras regiões continuam visíveis
apenas quando você alterna para a região correspondente.
+
WARNING: A região não pode ser alterada para recursos já provisionados.
Planeje a região antes de criar seus recursos.

=== Explorar o Console

==== Visão geral do painel

O painel do Console é organizado em três áreas principais: o catálogo de
serviços (à esquerda), a área de trabalho central e a barra superior, onde
ficam o seletor de região, o seletor de projeto e as notificações da conta.
Use o catálogo para abrir qualquer serviço, como *Elastic Cloud Server
(ECS)* ou *Object Storage Service (OBS)*.

===== Regiões e projetos

Cada região pode conter múltiplos projetos IAM. O seletor de projeto, ao lado
do seletor de região, permite isolar recursos por equipe ou finalidade. O
parâmetro *region* do provedor Terraform deve corresponder exatamente ao
identificador da região escolhida aqui, por exemplo `sa-brazil-1`.

== Configurar credenciais para a CLI

[.objectives]
====
[.general-objective]#Este capítulo mostra como obter um par de chaves de acesso
(AK/SK) no Console e declarar o provedor da Huawei Cloud em um arquivo
de configuração, preparando o ambiente para uso com a CLI e com
ferramentas de Infraestrutura como Código.#

*Pré-requisitos:*

- Acesso ao Console da Huawei Cloud concluído no Capítulo 1.
- Permissão IAM para criar credenciais de acesso.
- `terraform` instalado localmente (versão 1.0 ou superior).
====

=== Criar uma AK/SK

*Objetivo:* Gerar um par de Access Key ID / Secret Access Key para autenticar
ferramentas externas na Huawei Cloud.

No Console, clique no nome do usuário, no canto superior direito, e abra
*My Credentials*. Na seção *Access Keys*, clique em
*Create Access Key* e baixe o arquivo gerado. Guarde o arquivo em local
seguro: a Secret Access Key é exibida apenas uma vez.

=== Declarar o provedor

*Passo a passo:*

. Crie um arquivo chamado *provider.tf* no diretório do seu
  projeto com o seguinte conteúdo:
+
----
terraform {
  required_providers {
    huaweicloud = {
      source  = "huaweicloud/huaweicloud"
      version = ">= 1.60.0"
    }
  }
}

provider "huaweicloud" {
  region     = "sa-brazil-1"
  access_key = "SUA_ACCESS_KEY_AQUI"
  secret_key = "SUA_SECRET_KEY_AQUI"
}
----
+
Substitua os valores de *access_key* e *secret_key* pelas
credenciais obtidas na seção anterior. Alternativamente, você pode incluir
o código a partir de um arquivo externo:
+
[.codefile,file=assets/example-script.sh,lang=bash]
----
----
+
. No terminal, na pasta do projeto, inicialize o diretório de trabalho
  do `terraform`:
+
[source,bash]
----
terraform init
terraform plan
----
+
NOTE: Nunca versione o arquivo *provider.tf* com credenciais reais.
Use variáveis de ambiente ou um arquivo de estado ignorado pelo controle
de versão.

=== Próximos passos

Com o provider declarado, você pode começar a definir recursos no
`terraform`. Para conhecer todos os recursos disponíveis, consulte a
documentação oficial em
https://registry.terraform.io/providers/huaweicloud/huaweicloud/latest/docs[Huawei Cloud Provider].

TIP: Use `terraform validate` para verificar a sintaxe antes de aplicar
as alterações.

== Limpeza

[.objectives]
====
[.general-objective]#Remover os recursos criados neste laboratório para evitar cobranças contínuas.#
====

*Passo a passo:*

. No Console, navegue até *Elastic Cloud Server*.
. Selecione a instância `web-server-01`, clique em *More* e
  escolha *Delete*.
. Confirme a exclusão. Opcionalmente, libere o EIP se ele foi dedicado.

NOTE: Se você usou o Terraform, execute `terraform destroy` em vez disso
para remover todos os recursos declarados na configuração.
